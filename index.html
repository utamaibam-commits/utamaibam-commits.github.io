Sambungkan Ibam AI

  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Klik Create API key, lalu salin kuncinya.
  3. Tempel di kolom bawah, lalu klik Simpan.
Kunci disimpan hanya di browser ini (tidak dikirim ke server mana pun selain Google). Jangan bagikan kuncimu ke orang lain. Kalau muncul error model tidak ditemukan, ganti dengan nama model terbaru di ai.google.dev/gemini-api/docs/models. Paket gratis Google dapat memakai percakapan untuk meningkatkan produk mereka, jadi hindari mengirim data pribadi yang sensitif.
